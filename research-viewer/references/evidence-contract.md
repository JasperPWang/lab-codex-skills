# 实验可视化的数据与验收约定

这是跨项目的语义约定，不是可直接提交给某个注册器的 JSON schema。接入时复用项目现有 schema、字段名和验证器；缺少必要语义再扩展，并同时更新适配器、样例和相关验证。不要建立第二套平行清单。

## 身份与来源

| 对象 | 必须可追溯的事实 |
| --- | --- |
| 研究项目 | 稳定 project ID、显示名、研究目标、关联代码仓库 |
| 方法与运行 | repository/方法/变体与 run ID、代码 commit 或已声明的未知/dirty、配置和实验记录入口 |
| 样本 | 数据版本、split、sample/sequence/frame 身份、实际输入版本；跨方法匹配依据 |
| 资产 | 表示类型、登记资源 ID、来源与派生过程、版本/hash、大小与就绪状态 |
| 指标 | 名称/单位、好坏方向、计算来源、协议版本、适用样本与有效总体、缺失原因 |
| 查看状态 | 案例与资产版本、筛选/排序、适用的相机/图层/质量/frame/time |

绝对服务器路径、SSH 信息和凭据只在私有配置或受限服务侧清单中，前端使用受控资源 ID/URL。来源未知明确标记，不能编造 commit、GT、单位或标定。

## 状态与数量

至少分别表达以下事实，不合并为一个含糊的 `ready`：

- 输出：存在/缺失/生成中/生成失败。
- 查看：未验证/可加载/格式不支持/加载失败/资源受限。
- 评测：有效/尚未评测/不适用/无效及原因。
- GT：可用/不适用/缺失/来源待核对；派生 GT 必须说明变换协议。
- 对照：已核验可比/仅并列探索/不满足条件及原因。

输出缺失仍可展示有效输入和 GT；HTTP 失败不等于实验失败。指标缺失不用 0 替代，加载出错不回退到旧帧、示例或另一个方法的结果。

记录数、独立输入数、可展示案例数、有效评测数分别计算。排名在明确的方法/run/数据划分/协议总体内完成；跨方法指标对照先验证相同口径，缺失值不算最好或最差的数值。若只展示精选子集，说明选样依据及完整总体，不能据此宣称整体优劣。

## 可比性与动态证据

共享数据集名称或文件名不够：核对输入版本、split、样本/人体/物体身份、预处理、阶段、坐标变换和评价协议。未对齐结果允许并列探索，但不能标为严格比较。

静态三维遵循入口中的共享相机/投影与完整 Gaussian 规则。动态结果额外需要：

- 来源时间戳或明确帧映射，不把相同数组下标当作相同时间。
- 播放、暂停、seek 的公共时间状态；缺帧、不同帧率和预测起点显式处理。
- 各栏资源与解码就绪后才显示对应比较帧；过期异步结果不能写回当前选择。
- 截图/检查链接保存帧和资产版本；视频展示不冒充支持动态交互三维。
- 生成结果保留实际条件、seed/样本编号与预测范围；不能把未来 GT 输入混入预测条件，也不能静默丢掉失败采样。

## 不可变发布与最小验收

适配器只读原结果，转换写到独立导出位置，登记器校验格式内容、资源边界、hash 与身份关系。发布先完成清单和所有就绪资产，再原子切换索引。读取方不得混用不同 generation 的映射；已登记源资产若可变，使用独立版本或检测变化并拒绝冒充原版本。

执行与当前改动有关的检查：

1. 一个真实案例从页面反查到原输入/输出/指标，来源和数值匹配。
2. 缺失或失败不会静默替换结果，分页前排序与详情导航范围一致。
3. 对照具有明确可比性依据，三维/动态的共享状态实际有效。
4. 未登记/越界资源不可访问，实验源文件未被改写。
5. 切换案例能取消或丢弃旧加载并释放资源，首屏不加载重资产。
6. 代码、索引或资产更新后，旧检查链接明确恢复匹配版本或提示不匹配。

新建查看器按实际支持能力验证；小改动只重跑受影响检查。检查结果与未验证范围写项目记录，不把合成测试、截图数量或 HTTP 200 当成真实研究数据正确性的证明。
